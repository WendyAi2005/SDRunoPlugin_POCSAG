# 常见问题与故障排查

[返回项目首页](../README.md) · [操作指南](USER_GUIDE_CN.md) · [协议说明](PROTOCOL_NOTES_CN.md)

## SDRuno 看不到插件

1. 确认使用支持 Community Plugin 的 SDRuno，并优先使用本项目已验证的 1.41.1 x86 环境。
2. 确认 `SDRunoPlugin_POCSAG.dll` 位于 Plugin Control 选择的目录。
3. 完全退出并重启 SDRuno；仅复制 DLL 不会让已运行进程自动重新加载。
4. 确认插件是 x86，且系统已安装 Microsoft Visual C++ 2015–2022 Redistributable（x86）。缺少 `MSVCP140.dll` 或 `VCRUNTIME140.dll` 时插件/MapServer 可能无法启动。
5. 若替换 DLL 提示文件正在使用，先退出 SDRuno，并在任务管理器确认相关进程已经结束。

## 插件能打开，但没有任何消息

依次检查：

- SDRuno stream 是否已经启动。
- 频率是否准确，信号是否位于滤波器中心。
- 模式是否为 NFM，带宽是否适合目标信号。
- baud 是否与信号一致：512 / 1200 / 2400。
- 极性是否正确；当前铁路预设为 INVERTED，其他系统可尝试 AUTO 或 NORMAL。
- Squelch 是否切断数据脉冲。
- 信号是否过弱，或前端是否因增益过高而过载。

当前实验频点可先点击 `一键设置 821.2375 MHz / NFM / 15 kHz`，但不要把该预设用于所有 POCSAG 系统。

## 同步或错误很多，纠错计数持续增加

常见原因包括信号弱、频偏、强邻频干扰、接收前端过载、错误 baud 或错误极性。尝试：

1. 重新把载波放在 NFM 滤波器中心。
2. 逐步降低或提高 RF 增益，避免只追求瀑布“更亮”。
3. 关闭会改变数据波形的降噪、音频增强和静噪。
4. 核对 baud 与极性。
5. 在信号出现时观察同步、有效、错误与 RAW 段计数，而不是只凭听感判断。

可纠错不等于所有正文都可靠。若问题可复现，请导出 RAW。

## 为什么只有 BASIC ONLY？

BASIC 与 EXT 可以独立到达。`BASIC ONLY` 表示当前已得到严格有效的 Railway BASIC，但尚未匹配到有效 EXT；车次、速度或公里标仍可正常显示。等待后续 transmission，或检查原始消息页是否出现无效/截断的 `1234002`。

## 为什么只有 EXT ONLY？

`EXT ONLY` 表示当前已得到有效 Railway EXT，但没有匹配到有效 BASIC。机车号、线路与 GPS 仍可显示。可能是 BASIC 未收到、存在不可纠错码字、固定布局无效，或两部分没有通过目标匹配约束。

## 一辆车为什么出现两个目标？

`RailwayStateManager` 会按 transmission、车次、机车号和候选评分尝试复用或合并目标，但不会无条件把时间接近的两条消息拼在一起。若真实同一列车仍重复：

1. 记录两个目标出现的准确时间。
2. 打开 `协议 / RAW 详情` 保存截图。
3. 导出 RAW CSV 与 JSONL。
4. 提交 Issue，说明两个目标的车次、机车号、线路、时间和位置连续性。

地图 marker 以 `target_uid` 为键；后端合并后应发送 `target_remove` 删除旧 marker。浏览器仍残留时，刷新页面并一并报告本机接口快照。

## 地图打不开或显示“本机数据接口暂不可用”

检查：

- `RailwayMapServer.exe` 是否与插件 DLL 同目录。
- 同目录是否有完整 `web/index.html`、`web/app.js`、`web/style.css`。
- 插件按钮是否成功启动 MapServer。
- 浏览器地址是否为 <http://127.0.0.1:8765/>。
- 8765 端口是否被其他程序占用。
- 防火墙或安全软件是否阻止本机 EXE。

不要只打开 `127.0.0.1`；必须带端口 `8765`。MapServer 只监听本机，不接受局域网其他设备连接。

## 地图列表有数据，但没有底图

Leaflet 1.9.4 脚本和 OpenStreetMap 瓦片来自互联网。代理、DNS、防火墙、CDN 或 OSM 瓦片访问失败时，底图可能不可用；这不表示 SDR 解码停止。

如果目标列表仍更新，说明本机 HTTP/WebSocket 链路正常。检查浏览器网络、全局代理/TUN 设置和开发者工具中的外部资源错误。

## 地图坐标有偏移

在左侧“坐标调试 / 切换”检查：

- 原始格式是否应为 `NMEA 度分`，而不是直接把原始数字除以 1e6。
- 源坐标系是 WGS84、GCJ-02 还是 BD-09。
- 地图显示转换是否与源坐标系和底图一致。
- 弹窗中的 Lon/Lat RAW、DM、Radio GPS、Displayed、Map coordinate 与位置来源。
- 当前目标是无线 GPS、公里标估算还是 OSM 估算。

切换显示模式不会修改底层 RAW。若分值大于等于 60 或坐标范围非法，插件会标记 invalid，不绘制 marker。

## 只有公里标，没有 GPS，能定位吗？

只有在 `MileagePositionDatabase` 已经有同线路锚点时才可能定位：

- 完全相同公里标可使用本地精确锚点。
- 前后锚点间隔不超过 2.0 km 时可插值。
- 只有单侧锚点时不会外推。

数据库没有可靠样本时，程序不会把公里标直接当成地图坐标。

## OSM 为什么查询不到公里标？

OpenStreetMap 的中国铁路线路和里程标数据可能不完整、标签不统一或存在多个同名候选。当前查询要求线路标签和公里标共同唯一匹配；歧义或无结果时不会强行选择。OSM 是实验性补充来源，不保证每条线路都能查询。

## 正文一直显示 UNSET / RAW

这表示消息有正文，但 `(RIC, Function)` 尚未配置为 NUMERIC 或 ALPHA。点击 `正文映射`，或右键原始消息设置解释类型。不要仅凭某次可读字符就假定同一 RIC 的所有 Function 都相同。

映射文件：

```text
%APPDATA%\SDRunoPlugin_POCSAG\message_mappings.tsv
```

## 如何提交可复现的 RAW？

建议附上：

- RAW CSV 和 JSONL。
- 问题发生的日期与准确时间。
- 接收频率、模式、带宽、baud、极性。
- SDRuno 版本、接收设备和增益设置。
- 插件主窗口、协议/RAW 详情和地图截图。
- 预期结果、实际结果，以及是否可重复。

公开前请检查日志内容，并遵守当地无线电接收、记录和信息传播法律法规。
